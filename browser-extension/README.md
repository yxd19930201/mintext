# 青玉浏览器助手

青玉书房的可选浏览器扩展，用于执行用户明确创建的网页版任务：

- 检查番茄作者后台登录状态、读取作品和章节；
- 将青玉书房中的指定章节发布或覆盖到番茄作者后台；
- 在已登录的 DeepSeek / ChatGPT 网页中执行青玉创建的浏览器 AI 任务。

扩展只连接本机 `http://127.0.0.1:8000`，任务和结果均保存在本地青玉数据库中，不接入原项目云服务。

## 本地安装

1. 打开 Chrome/Edge 的扩展管理页面并启用“开发者模式”。
2. 选择“加载已解压的扩展程序”，选择本目录。
3. 保持青玉书房运行，打开扩展弹窗并点击“连接本机青玉书房”。
4. 发布前先在番茄作者后台完成登录；网页版 AI 任务则先登录对应网站。

发布、覆盖等写操作必须先在青玉书房“发布中心”中显式创建，不会自动批量发布。
