# Third-party methodology notices

The manuscript inspection features use independently implemented review ideas
informed by the following MIT-licensed open-source projects. No external model
weights or third-party runtime code are bundled by these two features.

- worldwonderer/oh-story-claudecode — multi-view story review and prose cleanup
  concepts: https://github.com/worldwonderer/oh-story-claudecode
- howells/fiction — full-manuscript critique dimensions covering structure,
  character, pacing, prose, and themes: https://github.com/howells/fiction
- harshaneel/humanize — rule-based AI-style indicator categories and detector
  limitation guidance: https://github.com/harshaneel/humanize
- stephenturner/skill-deslop — directness, rhythm, trust, authenticity, and
  density review dimensions: https://github.com/stephenturner/skill-deslop

The “AI-style trace” report is a stylistic risk assessment. It must not be
represented as proof that a text was or was not written by AI.
