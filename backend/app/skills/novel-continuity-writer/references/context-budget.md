# 写作上下文预算

目标是移除无关历史和重复规则，而不是压缩正在创作的关键事实。

| 材料 | 建议上限 | 默认读取 |
|---|---:|---|
| `01` | 20KB | 提取相关硬规则 |
| `02` | 25KB | 是 |
| `03` 写前合同 | 15KB | 是，完整读取 |
| 相关线索账本条目 | 仅关联 ID | 是 |
| 上一章正文 | 1 章 | 按需 |
| 卷级正史摘要 | 当前卷与相关人物/线索 | 按需 |
| 记忆差异单 | 仅最近或待同步批次 | 按需 |

写作包顺序：读者承诺、不可违背事实、相关线索 ID、批次因果、每章标题与功能、禁止重复项、文风约束、上一章末尾。

禁止默认复制整卷正文、全部旧审核报告、完整线索账本或全部历史差异单。
