# 番茄男频擦边爽文：高黏性自然叙事

本文规定正文如何同时做到：**香、爽、险、好懂、想点下一章**。

擦边不是福利插段，而是追读发动机。让欲望推动人物靠近，让危险阻止彻底兑现，让身体距离改变关系、信息、资源或风险。

设计文件里的“香”一律指擦边。普通信任、并肩、护短、递证据、利益绑定或人物关心，若没有实际暧昧动作、双关、身体距离与双方回应，不能记为“香”。

所有涉及暧昧与亲密的角色必须明确成年、清醒、自愿、能够拒绝。不得利用醉酒、药物、失去意识、装睡、恐惧、职位、债务或依附关系替代同意。以临界感、双关和后果为主，不堆器官名或展开机械性行为过程；项目另有亲密设计时仍服从`01`与对应设计文件。

## 一、核心读感

始终追求：

```text
先让读者想歪
再给一个合理解释
刚解释清楚，又把距离往前推
快要越线时，让危险或正事闯进来
最后把欲望留下的后果挂回主线
```

每场擦边至少同时拥有三条线：

```text
欲望线：谁想靠近，为什么不肯先说破
正事线：两个人眼下必须办什么
风险线：被发现、失控、失去什么
```

缺正事，容易像硬插福利；缺风险，没有心跳；缺双方欲望，只剩单方面打量。

## 二、擦边七层

按场景需要选层级，不要求逐级全部出现。

1. **形**：衣料、湿发、腿线、腰线等一两个有效细节。禁止身体部位盘点。
2. **触**：按摩、疗伤、搀扶、避让、整理衣领等合理接触。
3. **意**：一句话有正常解释，也能让人想歪。
4. **势**：职业边界、身份差、旧账、竞争关系让靠近变得不方便。
5. **险**：敲门、电话、脚步、查房、镜头、第三人逼近。
6. **局**：擦边改变证言、交易、关系、资源、秘密或敌我判断。
7. **止**：在想象最强处打断，把未完成动作变成下一次追读承诺。

低级写身体，中级写距离，高级写危险，顶级写人物明知不方便靠近，却各有理由不肯退开。

## 三、场景发动公式

优先使用：

```text
一件普通正事
→ 合理接触
→ 一句容易想歪的话
→ 对方回击或允许
→ 距离再近一点
→ 第三人/危险逼近
→ 临界处打断
→ 正事产生新结果
```

可用的普通正事包括：按摩、疗伤、换药、躲雨、挡镜头、找东西、换衣、检查伤口、扶人、藏证据、谈价、等人、锁门对账。

天气、摔倒、停电只能开门，不能替人物完成关系变化。真正的推进必须来自人物自己的选择：留下、允许、回击、帮忙、遮掩、偏袒、说谎或主动退开。

### 双误会结构

让同一场景同时存在两种理解：

- 读者先误会，随后知道是正常服务；
- 门外第三人误会，屋内人物必须压低声音应付；
- 一句业务话被另一人故意往暧昧处理解；
- 一个动作原本为救急，事后却留下关系证据。

误会揭晓后不能泄气。合理解释必须保留真实的身体距离、欲望或风险。

## 四、第一章强兑现

擦边题材第一章必须兑现书名和标签，不能先讲两千字背景。

建议节拍：

```text
前150字：一句双关或一个带身体距离的动作
前500字：说明人物为何在一起，并出现第一次来回
前1000字：落下身份、能力或穿越错愕
中段：欲望与主要危机合流
章末：危险到场，或临界动作被打断
```

穿越文不得只写“记忆涌入，他接受了”。必须写出陌生身体、镜中脸、声音、衣服、触感、年龄或职业动作造成的认知错位。

穿越前受辱不得抽象概括“他很窝囊”。用两至四件会让读者生气的具体事：功劳被抢、被迫背责、钱被扣、当众道歉、求助被拒。最后让主角做一次仍有底色的选择，证明他不是纯废物。

第一章的擦边必须至少完成一项主线功能：触发能力、提供证言、暴露秘密、引来敌人、建立主要关系或造成误会证据。

## 五、身体距离阶梯

不要突然扑上去。让距离一寸一寸变化：

```text
看见
→ 同处狭小空间
→ 衣料或物件相碰
→ 合理接触
→ 对方没有退并主动回应
→ 明确询问或主动允许
→ 临界位置停住
→ 被打断或主动收回
```

每次升级只多一点。写清谁先动、谁看见、谁允许、谁停手。

同意要自然落在现场：

- 主动把手、腿或物件递过去；
- 明确说“可以”“继续”“是我让你做的”；
- 对方停下后，再由另一方主动拉回；
- 玩笑之后仍给出真实选择。

沉默、僵住、怕失去工作、怕得罪人、醉酒和不敢反抗均不算同意。

## 六、双关对白

对白要短、土、能接动作。允许直接、低俗、嘴坏，但不要写成黄词清单。

常用结构：

### 命令被误解

```text
“轻点。”
“是这里疼，还是我碰哪儿都疼？”
```

### 业务边界变调情

```text
“再往上就不是原来的项目了。”
“那我加钱。”
```

### 嘴上赶人，动作留人

```text
“你可以走了。”
她说完，却还抓着他的袖口。
```

### 第三人追问

```text
“里面什么声音？”
“桌子歪了。”
“修桌子需要关门？”
```

### 明确询问

```text
“我再近一点，你要不要我停？”
“你先别替我做决定。”
```

不要让每句话都聪明。人物可以听岔、重复、嘴硬、改口、先骂人再答应。台词已经表达清楚时，不要追加“这是一场试探”“她已经默许”。

## 七、空间、物件与第三人

先画清空间：门在哪里，谁能看见谁，衣服、毛巾、钥匙、手机、杯子放在哪里。

一场戏选两三件普通物品，让它们连续变义：

```text
毛巾先用于服务
→ 后来遮挡距离
→ 最后被第三人看见，成为关系证据
```

优先使用声音制造偷感：

- 门外脚步；
- 手机突然播放语音；
- 电梯到层；
- 钥匙插锁；
- 隔壁有人问话；
- 镜头正在直播；
- 雨声盖住一句话，又让另一句话被听见。

第三人不能只负责打断。他应带来真实后果：误会、流言、证言、嫉妒、把柄、敌意或新的交易条件。

## 八、女性角色与双方主动

女性角色必须有自己的欲望、利益、判断和边界。她可以主动、好色、会算计、会吃醋、会反悔，也可以用暧昧谈价、试探忠诚或争夺资源。

每个主要女性场景至少回答：

- 她眼下想办成什么事？
- 她为何选择靠近，而不是直接说？
- 她能够拒绝什么？
- 她靠近后得到或失去什么？

暧昧必须有来回：凝视与反看、逗弄与回击、主动与回应、靠近与停手。单方面扫视身体不算关系戏。

主角可以馋、嘴欠、会想歪，但关键动作要聪明并守边界。守边界不是清心寡欲，而是让人物更有掌控力，也给对方下一次主动的空间。

## 九、擦边怎样进入主线

每场主擦边必须改变至少一项：

- **信息**：发现伤病、秘密、谎言或不在场证明；
- **关系**：改称呼、偏袒、短吻、避嫌、吃醋、第一次明确拒绝；
- **资源**：货源、客户、钥匙、号码、工作或交易条件；
- **风险**：被看见、被录下、留下痕迹、引来第三人；
- **位置**：谁站在门内，谁被挡在外面，谁开始有资格说话。

删掉擦边场景后主线完全不变，判定为硬插福利，必须重写或删除。

亲密之后先写余波：整理衣服、擦掉痕迹、换称呼、接电话、处理门外的人、发现少了一件东西。不要立刻总结爱情意义。

## 十、标题的一题两解

标题既要能让人想歪，又要在章内字面兑现。

常用类型：

1. **边界句**：《再往上就过线了》
2. **动作句**：《她没让他松手》
3. **身份反差**：《废柴今天开窍了》
4. **香险混合**：《门外有人，她还没退》
5. **利益双关**：《这双手，她加价两千》
6. **结果双义**：《今晚差点出人命》

标题验收四问：

- 不看正文，三秒内能否出现画面？
- 是否有正常解释与暧昧解释？
- 章内是否真的发生对应动作？
- 看完后是否觉得兑现，而不是被骗？

禁止连续五章都用“她、腿、亲、湿”等相同刺激词。标题要在香、爽、险、秘密、利益之间轮换。

## 十一、三至五章轮换

默认五章批次建议：

| 章位 | 主要读感 | 擦边功能 |
|---|---|---|
| 1 | 强钩与身份错位 | 主擦边，直接兑现标签 |
| 2 | 洗罪或危机 | 短距离、验伤、偏袒 |
| 3 | 能力或立威 | 战后贴近、差一点兑现 |
| 4 | 外部危险 | 湿衣、藏人、挡镜头或第一次短吻 |
| 5 | 关系竞争与新麻烦 | 新人物主动、利益挖人、修罗场 |

这只是轮换示例，不得机械复制。每批至少变换：

- 接触载体；
- 谁先主动；
- 空间；
- 第三人；
- 被打断方式；
- 主线收益。

连续两次“差一寸接吻被电话打断”即视为重复。连续三章只写亲密、不推进争斗、经营或大主线，必须退稿。

## 十二、爽点与擦边换轨

擦边推到临界后，立即换入危险或爽点：

```text
想靠近
→ 被撞破/被威胁
→ 主角作出选择
→ 能力或专业兑现
→ 对手付出代价
→ 关系留下新痕迹
```

不要把高潮全耗在身体描写上。读者期待被吊起来后，用翻案、救人、打脸、交易或反杀结算，爽感会更强。

胜利必须有可见收益和余波：钱、钥匙、客户、号码、证据、破掉的门、未付的维修费、对手的新恨。

## 十三、自然口语与段落

正文像一个懂人情、爱看热闹、偶尔嘴坏的人讲真事。

- 从普通小事开门，不先讲势力说明书；
- 含对白段落可占一半到三分之二；
- 段落长短混合，几个短对白后接完整动作；
- 常用“说、问、拿、放、看、走、笑、愣”不丢人；
- 少用“骤然、蓦然、眸光、弧度、意味深长、空气凝固”；
- 不让所有人统一震惊，拆成各自不同反应；
- 不写三个以上同构短句组成的口号。

### 一二三式摆拍腔（展品式枚举）

以下组合是高风险 AI 腔：先报时间地点，再宣布“摆着、放着、来了、共有 N 样东西”，随后把三个以上物件各自拆成一行名词短句。它语法没错，却像作者布置橱窗：物件先排队，人物后进场，句长和节拍过分整齐。

功能性清点不一律禁止。人物确实在盘点、点名、核账，且数量会改变决定或冲突时可以写；但物件要随人物的拿、压、踢、抢、藏、递和争执出现，句长要有变化，不能仍是“一个物件一行”的展览。删掉“有三样东西”后若只剩一张静态陈列照，就把场景改成动作过程。

一章只讲一桩容易复述的小事。人物各有小心思，互相推一下，事情自然滚大。

## 十四、四遍返修

### 第一遍：主线

检查删掉擦边后剧情是否不变。若不变，补信息、关系、资源或风险收益。

### 第二遍：张力

检查是否只有看身材，是否缺双方来回，是否一步越线，是否没有第三人或危险。把接触改成阶梯，把解释改成动作。

### 第三遍：人话

删除动作后的标准答案和关系翻译。让人物误会、嘴硬、改口、答非所问，但不降智。

### 第四遍：标题与AI腔

检查标题是否一题两解、章内兑现。搜索并处理：

```text
他知道　他明白　他意识到　这意味着　显然　毫无疑问
筹码　窗口　闭环　落地　站队　不可逆　真正的较量
不是X而是Y　没有X只有Y　所有人的目光都变了
```

能由动作看懂的整句删除；看不懂的补物件、声音、位置或对话。

另查“时间地点 + 摆了N样东西 + N行孤立名词短句”。不要只把几行合并成一句；要让人物真正碰、用或争夺这些物件，使它们在冲突中陆续露出来。

## 十五、起草与交稿门槛

起草前只记：

```text
先给一件正事。
再给双方不同欲望。
用合理接触缩短距离。
用双关让读者想歪。
用第三人或危险逼近。
临界处换入主线结算。
```

交稿前逐项回答：

- 第一章是否在前150—300字兑现擦边标签？
- 擦边是否有合理正事承载？
- 是否明确成年、清醒、自愿并能拒绝？
- 是否有双方来回，而非男主单方面扫视？
- 身体距离是否逐级推进？
- 是否有第三人、危险或被发现风险？
- 场景是否改变信息、关系、资源或风险？
- 标题是否一题两解且章内兑现？
- 本批是否换了接触载体、主动方和打断方式？
- 临界后是否转入爽点或主线，而不是拖成纯肉？
- 正文是否仍像人在说话，而不是执行公式？

任意三项答不上来，不进入审核。
