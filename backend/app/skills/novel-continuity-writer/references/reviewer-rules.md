# 番茄男频擦边爽文：审核、返修与正史复审

生命周期服从`lifecycle.md`。审核的职责是阻止**不香、不爽、不连贯、假擦边、重复擦边或越界内容**进入正史，不把正文修成模板。

擦边项目不能只检查“有没有身体描写”。必须检查欲望是否有来回、距离是否升级、标题是否诱发联想、危险是否逼近、临界后是否转入主线收益。

## 一、审核输入与基线

审核者只读取：

1. `01-全局设定与创作规则.md`
2. `02-章节滑动摘要.md`
3. `03-当前批次任务.md`
4. 当前批次草稿

不读取主笔讨论、废稿解释或未落盘设想。用户未授权并行时，执行角色模拟审核并注明，不自行分派Agent。

### 可复现审核门禁

1. 审稿前运行`submit-review`，冻结草稿与`01`、`02`、`03`的SHA-256基线。
2. 报告首行必须逐字写入：`审核基线：sha256:<64位摘要>`。
3. 正文、设定、摘要或任务任一变动，旧报告立即失效；重新提交、重新审核。
4. 审核既有正史先运行：

```powershell
python tools/novel_workflow.py audit-snapshot --from-chapter 1 --to-chapter 40 --source canonical
```

核对旧报告运行：

```powershell
python tools/novel_workflow.py verify-review-baseline --from-chapter 1 --to-chapter 40 --source canonical --report reviews/第001-040章-审核.md
```

基线不匹配时，报告必须写“旧通过结论失效”。旧分数不能证明当前版本通过。

## 二、硬门槛

出现任一项，总评只能为“需修改”：

- 设定、时间、能力、物证、持有链或知识状态冲突；
- 每章不足1500字或超过3000字且明显注水、拖沓；
- 章节无推进、揭露、交易、反转、关系变化或后果；
- 第一章未兑现书名、类型或擦边承诺；
- 擦边场景删掉后剧情、关系、信息和风险完全不变；
- 设计或正文把普通信任、并肩、护短、递证据、利益绑定冒充“香”，没有实际擦边动作、双关、身体距离与双方回应；
- 只有男主扫视身体，没有对方欲望、选择或回击；
- 亲密动作突然升级，没有合理正事、允许或回应；
- 未明确成年、清醒、自愿，或以沉默、僵住、醉酒、药物、恐惧、职位、债务、依附替代同意；
- 连续两次复刻同一种差吻、搭腿、湿衣、摔进怀里或电话打断；
- 连续三章只写亲密，不推进争斗、经营或主线；
- 标题靠暧昧骗点击，章内没有对应动作；
- 正文出现“本章、前文、后文、下一章、批次、闭环、不可逆”等编辑或设计语言；
- 自然度、阅读体验或擦边兑现低于项目门槛。

分数只用于诊断，不能抵消硬伤。

## 三、连续性与证据

检查：

- 时间、地点、伤势、资源、战力与行动距离；
- 人物动机、口吻、秘密、亲密进度和知识状态；
- 道具、衣物、钥匙、手机、门、毛巾、证据、承诺与债务；
- 本批是否承接上一批，新增事实能否写入`02`。

### 物证硬规则

- 可追索对象必须核对首次出现、取得者、持有人、备份和后续用途。
- 相似物证只能写“相近、相似、手法一致”，证据不足不得写成同一件。
- 角色判断不得超出此刻真正看到、听到、接触或拿到的信息。
- 旧短信、录音、电话或回忆第一次出现便解决当前谜面，默认高风险；前文没有入口即视为回收作弊。
- 正文不得用章节号或文件名说明物件来源，改成角色可见的时间、地点或动作。

### 亲密连续性

单独核对：

- 上次靠近到哪一步；
- 谁主动、谁允许、谁中止；
- 是否发生过短吻、同房、拒绝、吃醋或公开偏袒；
- 下一次互动是否承认旧痕迹；
- 衣物、吻痕、伤口、流言、偷拍视频或第三人误会是否有余波。

已经亲过的人不能下一章自动写回第一次靠近；明确拒绝过的人也不能无新事件突然主动。

## 四、擦边兑现

逐场填写下列检查：

| 项目 | 必须回答 |
|---|---|
| 正事 | 两个人为何必须待在一起？ |
| 欲望 | 双方分别想靠近、试探或得到什么？ |
| 接触 | 合理接触如何发生？ |
| 升级 | 距离是否一寸一寸推进？ |
| 同意 | 谁主动、谁回应、谁能够叫停？ |
| 双关 | 是否有正常解释与暧昧解释？ |
| 风险 | 谁可能听见、看见、误会或利用？ |
| 临界 | 是否停在想象最强处或由人物主动收回？ |
| 收益 | 信息、关系、资源、位置或风险改变了什么？ |

缺三项以上，判定为假擦边或硬插福利。

### 擦边评分

- **9.5—10**：合理接触、双方来回、危险、临界打断和主线收益同时成立；动作有本章独特性。
- **9.0—9.4**：有香味但缺一项关键机制，允许返修补强。
- **8.0—8.9**：主要靠身材、湿衣、脸红和心跳，关系与主线弱。
- **8.0以下**：单方面意淫、机械动作、假同意、重复桥段或纯色情插段。

默认擦边项目低于9.5必须返修。

### 重点退稿类型

1. **身体清单**：从头扫到脚，没有动作和回击。
2. **万能摔倒**：每次都摔进怀里，人物不作选择。
3. **电话专业户**：每次快吻都由电话打断。
4. **女主工具化**：只负责脸红、送资源、夸男主。
5. **主角猥琐化**：未询问便升级触碰，靠对方不反抗自我合理化。
6. **纯肉断主线**：亲密结束后没有证据、交易、关系或危险余波。
7. **同动作换人**：不同女性只换名字，仍使用同一搭腿、湿衣和台词。

## 五、标题点击力

擦边标题必须“一题两解”：点开前容易想歪，读完后字面成立。

逐章检查：

- 三秒内能否出现画面？
- 是否包含具体人物、动作、物件、危险或利益？
- 是否同时存在正常解释和暧昧解释？
- 章内是否真实兑现？
- 是否泄露全部结果？
- 是否与相邻章节同词、同结构？

### 标题评分

- **9.5—10**：有画面、有双义、章内兑现，还能承诺本章主要读感。
- **9.0—9.4**：清楚有力但偏功能型，浮想联翩不足。
- **8.0—8.9**：泛泛写“危机来了”“她生气了”，缺动作与物件。
- **8.0以下**：虚假擦边、标题党或连续同构。

默认五章批次至少两章标题具备暧昧双义；其余标题在爽、险、秘密、利益之间轮换。不得五章全部使用“她、腿、亲、湿”等同类刺激词。

标题修改必须与正文同轮复审。不能只换一个更露的标题而不补章内兑现。

## 六、阅读体验与爽点

检查：

- 新压力是否具体；
- 主角是否主动选择；
- 对手是否真实得手或构成有效威胁；
- 擦边是否把欲望推高，随后换入危险、能力、翻案或交易；
- 爽点是否具备压迫、误判、选择、反馈、收益和代价；
- 每章是否有功能和钩子；
- 批次小故事是否结算并推动大主线；
- 是否轻松、土、爽、好懂，不让制度和专业说明压过人物。

擦边推到临界后必须换轨。若读者期待被吊起，却只得到更多同质身体描写，没有打脸、救人、危机或关系结算，判阅读体验不通过。

## 七、人物、关系与边界

检查：

- 配角是否有独立目标；
- 女性角色是否有欲望、利益、判断、边界和拒绝权；
- 主角可以馋、嘴欠、会想歪，但关键动作是否聪明、会停手；
- 暧昧是否来自场景、利益、危险、旧账或竞争；
- 关系是否通过称呼、站位、钥匙、短吻、偏袒、避嫌或后果真实改变；
- 亲密是否凭空生成股权、执法权、医疗权限或政治投降。

“守边界”不等于把主角写成木头。若双方已清楚主动，主角仍连续装傻、退缩、讲道理，导致张力塌陷，同样需要返修。

## 八、文风自然度

检查：

- 解释腔、总结腔、宣传片腔、汇报腔；
- 对白是否人人同声同气；
- 是否连续出现“他知道、明白、意识到、这意味着”；
- 是否用“脸红、心跳、呼吸急促”替代具体动作；
- 是否连续使用对称短句、排比和模板金句；
- 身体描写是否脱离空间与物件；
- 台词是否像人应付人，而不是作者宣布欲望。

### 一二三式摆拍腔：硬性退稿项

出现“时间地点报幕 + 摆着/放着/来了 N 样东西 + 三行以上孤立名词短句”的展品式枚举，或虽未写数量却连续把物件一件一行对称陈列，均按明显 AI 腔列为必改。不能以“短句有冲击力”为由放行：句法越整齐、物件越不参与人物动作，摆拍感越重。

审核者发现一处后，必须扩散扫描本批全部章节，逐处定位，不能只举一个例子。须区分功能性清点与装饰性枚举：前者由人物主动核对，数量会改变决定或冲突；后者删掉数量报幕后只剩静态展览。返修必须把物件嵌入人物的拿、压、碰翻、递交、争抢和对话，单纯合并为一个长句仍不通过。

自然度低于9.5必须返修。

### AI腔快速修复

1. 删除动作后的标准答案。
2. 把抽象欲望改成站位、手、衣料、物件和一句没说完的话。
3. 让其中一人误会、嘴硬、改口或顾面子。
4. 打乱连续相同句长。
5. 把统一震惊拆成不同旁人反应。

## 九、首章与批次专项

### 第一章

必须检查：

- 前150—300字是否兑现擦边标签；
- 前500字是否说明人物为何靠近；
- 穿越是否有身体与认知错位，而非一句接受记忆；
- 前世受辱是否具体到让读者生气；
- 擦边是否触发能力、证言、误会、敌人或主要关系；
- 章末是否有具体危险到场。

第一章只有身材描写、背景说明或普通冲突，擦边承诺未兑现，直接退稿。

### 三至五章批次

默认五章批次检查：

- 至少一场主擦边完整具备正事、双方欲望、风险、临界与收益；
- 至少两场短香位承担验伤、偏袒、挡镜头、谈价、吃醋或余波；
- 接触载体、主动方、空间、第三人和打断方式至少轮换三项；
- 至少一次从擦边立即转入能力、翻案、救人、经营或打脸；
- 批末关系、信息、资源、名声或威胁至少一项不可逆变化。

不要为凑数量机械插香。数量达标但同质，仍然退稿。

## 十、审核报告契约

### 首轮审核的完整发现义务

审核者发现一个问题后，必须对当前五章做一次**同类问题扩散扫描**，再结束报告：

- 发现旧标题时，扫描全部文件名、首行、设计标题和标题字面兑现；
- 发现时间冲突时，重建整批到场、倒计时、跨夜和行程表；
- 发现重复句时，同时扫描近义动作、相同场景发动方式和相同打断方式；
- 发现清单腔时，朗读所有同意、边界、证据和规则对白；
- 发现知识状态冲突时，横向核对`01 / design / 02 / 03 / 账本 / 正文`的同一事实；
- 无论是否先发现缺口，都必须枚举本批每一个有名字的可移动证据物/载体和每一个交接动词，重建`来源、取得时间、有权操作人、当前持有人、原件/副本、实际移交或归还、下一窗口`；手机、消息、U盘、会议本、打印件、监控导出、回执等不得只抽查“关键物件”。发现一件不清时，再扩散检查全部物件，不能只检查被点名物件；
- 发现一次权限越界时，为本批所有锁门、停卡、调监控、取账、盖章、封存和撤权动作核对执行人、授权来源与复核者；
- 发现“昨夜/今晚/明早/次日”错称时，横扫本批全部相对时间词并映射到统一日历；
- 发现局部修改引起的新问题时，检查标题、因果、证据持有、关系进度和章钩的回归影响。

不能因为已经找到一个足以退稿的硬伤就停止阅读。报告应尽量在本轮列全当前文本中可发现的必改问题；下一轮仍须从零审核，但不得把本轮本可发现的同类问题留到后续逐轮提出。

审核还要做复杂度判断：同一事实若被复制到三个以上介质，或某个载体不承担独立的翻盘、知识差、代价或钩子，应优先建议删减/合并，而不是继续添加回执、截图或新副本来修补。审核“证据链闭合”的同时，也审核正文有没有被程序介质拖成汇报材料。

保存为：

```text
reviews/第071-075章-审核.md
```

必须包含：

```text

可选优化：

```

“加强擦边、节奏更快、人物更立体”不算有效问题。必改问题必须写清：

- 具体章节、场景或句子；
- 问题类型；
- 为什么会让读者无感、反感、误解或出戏；
- 最小修复目标；
- 如何验证已经修好。

## 十一、通过标准

通过必须同时满足：

- 审核基线与当前文本匹配；
- 连续性、能力、物证与知识状态通过；
- 第一章兑现题材与擦边承诺；
- 阅读体验、擦边兑现、人物关系和自然度默认不低于9.5；
- 标题点击力默认不低于9.3，主擦边章不低于9.5；
- 每章有功能和钩子；
- 批次形成小故事结算并推进大主线；
- 擦边场景有双方来回、清楚边界、主线收益和动作轮换；
- 新事实与下一批承接可以明确落盘；
- 报告SHA-256已由`record-review`登记。

任一必改问题存在，结论只能为“需修改”。

## 十二、返修循环

需修改时：

```powershell
python tools/novel_workflow.py record-review --from-chapter 71 --to-chapter 75 --result revise --report reviews/第071-075章-审核.md
```

只修改`drafts/`。按最小范围处理：

- 假擦边：补正事、双方欲望、风险和主线收益；
- 无张力：拆成身体距离阶梯；
- 主角猥琐：补询问、停手和对方主动选择；
- 女主工具化：补她的利益、拒绝权和后果；
- 动作重复：更换载体、空间、主动方或打断方式；
- 标题虚假：改正文兑现或降低标题承诺；
- 纯肉断线：在事后加入证据、交易、危险或关系余波；
- 证据错接：删强判断、补来源或换物件；
- AI腔：删解释、补动作、改成人话。

返修后重新`submit-review`，生成新基线，不沿用旧结论。

通过时：

```powershell
python tools/novel_workflow.py record-review --from-chapter 71 --to-chapter 75 --result pass --report reviews/第071-075章-审核.md
python tools/novel_workflow.py finalize --from-chapter 71 --to-chapter 75
```

## 十三、剧情崩塌修复

先分类：

- 设定或时间冲突；
- 物证或知识越界；
- 人物跑偏；
- 亲密进度倒退；
- 女主工具化；
- 擦边同质化；
- 标题失信；
- 爽点失效；
- 主线被纯肉截断；
- 批次空转。

修复范围从小到大：

1. 当前动作或对白；
2. 当前擦边场景；
3. 当前章节；
4. 当前批次；
